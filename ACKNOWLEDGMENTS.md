# Acknowledgments

STARTcloud Scripts is built using many excellent open-source projects and tools. We are grateful to the developers and communities behind these projects.

## Core Dependencies

### Runtime Dependencies

**ksh93u+m** - KornShell 93u+m

- Repository: [github.com/ksh93/ksh](https://github.com/ksh93/ksh)
- License: EPL-2.0
- Usage: Interpreter for the scripts

**OpenZFS** - ZFS file system and volume manager

- Website: [openzfs.org](https://openzfs.org/)
- License: CDDL
- Usage: Snapshot creation and retention

**Debian** - The universal operating system

- Website: [debian.org](https://www.debian.org/)
